# Local data directory

Source files stay outside Git because they are large, supplied by others, or
generated by the project. Do not upload them with code changes.

- `housing/` holds the manually downloaded Zillow ZIP-level ZHVI CSV.
- `geo/` holds the manually downloaded Census ZCTA shapefile and sidecar files.
- `acs/` holds the ACS CSV saved after a successful API-based load. The original
	reference notebook also writes this file if run.

The PostgreSQL source tables retain all 250 matched study ZCTAs, including missing
ACS home-value estimates. SQL views select the 248 rows used for analysis.
The Python reader supplies those rows to the model and figure commands without
changing source files. GeoPandas reads map shapes locally; no PostGIS is required.
Neither notebook is needed by this workflow. Both remain references until the
planned Tableau report is checked and they are removed in a separate commit.

`--acs-file` explicitly reuses the trusted 2022 extract. The existing CSV has no
year column, so do not substitute another year under that option.

See the repository [`README.md`](../README.md) for exact filenames, download links, and setup instructions. Do not commit API keys or the ignored source data.
