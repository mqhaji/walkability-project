# Local data directory

The analysis uses source files that are intentionally excluded from Git because they are large, externally distributed, or generated at runtime.

- `housing/` holds the manually downloaded Zillow ZIP-level ZHVI CSV.
- `geo/` holds the manually downloaded Census ZCTA shapefile and sidecar files.
- `acs/` receives the ACS extract generated by the notebook.

See the repository [`README.md`](../README.md) for exact filenames, download links, and setup instructions. Do not commit API keys or the ignored source data.
