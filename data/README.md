# Local data directory

The analysis uses source files that are intentionally excluded from Git because they are large, externally distributed, or generated at runtime.

- `housing/` holds the manually downloaded Zillow ZIP-level ZHVI CSV.
- `geo/` holds the manually downloaded Census ZCTA shapefile and sidecar files.
- `acs/` receives the ACS extract generated by the reference notebook or after a successful API-based pipeline load.

The PostgreSQL source tables retain all 250 matched study ZCTAs, including missing
ACS home-value estimates. PostgreSQL views reproduce the 248-row analytical
sample through the read-only Python reader used by
`notebooks/walkability_analysis_postgres.ipynb`. The original notebook remains an
independent reference. Geometry remains a local GeoPandas input; no PostGIS is
required. The database-backed notebook does not read or rewrite the source CSVs.

`--acs-file` explicitly reuses the trusted 2022 extract. The existing CSV has no
vintage column, so do not substitute another year under that option.

See the repository [`README.md`](../README.md) for exact filenames, download links, and setup instructions. Do not commit API keys or the ignored source data.
